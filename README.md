# Obvious

A standalone, buildless site about combinatorial input spaces and **Patterns Populations Management (PopMan)**, nicknamed **Pops**. Its pattern store natively accepts, combines, prunes, and infers over encoded multimodal inputs. The intelligence contract is input matrix → brain / processor → output matrix for effectors.

Open `index.html` in a modern browser. Upload the **contents of this folder** as the document root of a static host. No installation, build command, server application, API key, or database is required. The site uses relative paths and also supports hosting below a repository-name URL prefix.

The five introductory explanations are **Principles 1–5**. The examples are **Clues 1–10**, consistently named in headings, lab titles, navigation, and Part 3 citations. 
## Evidence labels

- Green: an observation or independently established phenomenon.
- Blue: a runnable computational demonstration or historical recorded demonstration.
- Gold: an architectural design, schematic animation, or plausible mapping.
- Purple: a conjecture or proposed biological interpretation.

A runnable simulation does not establish its biological interpretation. Part 3 links directly to the relevant Part 2 examples, and Tier A cards link independent papers about the phenomena. The proposed PopMan accounts remain to be tested.

## Lab scope

- **Clue 1:** configured hard-AND detectors; reports actual position coverage, effective fan-in, theoretical selectivity, and sampled error counts. It does not learn the target.
- **Clue 2:** position-aligned target fragments, a bounded sliding sensor, retained activation traces, and a K-of-N event threshold. Traces reset between sequences. The event predicts target recognition; it does not generate unseen symbols.
- **Clue 3:** quantized sinusoid populations, shared dictionaries, multiple similarity measures, and optional explicitly labeled feedback. The compact default reserves approximately **14.5 MiB** of typed arrays, plus browser overhead, with a 32 MiB array-budget ceiling. Capacity exhaustion stops all streams while retaining committed evidence. There is no disk persistence. The historical screenshot shows an earlier configuration.
- **Clues 4–7:** historical recordings/images. The corresponding original training applications, datasets, seeds, and complete reproduction procedures were not supplied in this workspace. The stock screenshot depicts a historical profit comparison, not a hierarchy diagram or an investment recommendation.
- **Multimodal examples:** MNIST combines pixel patterns with gaze movement; Stox combines market-input channels such as open price and volume. The experiments remain unfinished; native multimodal pattern handling is a property of the store, separate from application completion. IMDb remains the text-sentiment example.
- **Clue 8:** schematic storage/retrieval animations, not a measured billion-pattern paging benchmark. Persistent storage is finite; adaptive retrieval/distributed workflows require indexing and compatible merge semantics.
- **Clue 8 P.S.:** the author's account of an early three-layer experiment (2 × 3 × 3 input composition, spanning 18 character positions), symbolic ID reuse, pruning across dependent layers, and heuristic mining of long shared subsequences. Wildcarded spans are distinguished from fully specified sequences; extensible depth is distinguished from unlimited resources. This is historical experimental context, separate from the schematic animations and an exact MLCS solver.
- **Clue 9:** a toy arrival-time competition. Depth is a configured proxy for specificity; conduction delays are assumptions. This is not a biophysical myelination model.
- **Clue 10:** local text-pattern learning, exact next-token retrieval with suffix fallback, live mean-cosine context reranking, context-seeded continuations, and learned World Model ZIP snapshots. Context dictionaries contain exact 1–3-token counts; training wildcard families are separate. Context ranks the current candidates. A language/genre switch is not guaranteed; selecting a new context seed resets the continuation while retaining learning. The edge artwork represents possible contributors; one learner runs here. The engine is unchanged from the accepted standalone lab. Train includes inline instructions for saving and loading World Model ZIPs.
