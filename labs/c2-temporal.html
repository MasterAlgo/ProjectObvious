OBVIOUS — Clue 2: Temporal ABRACADABRA Demo

This demo extends the spatial pattern detector into the temporal domain — and adds one key idea: prediction from partial evidence.

The target sequence "ABRACADABRA" (11 symbols, 5 unique letters, 511 ≈ 48.8M possible input states) is presented one symbol at a time, stride by stride. A sliding sensor window of adjustable width moves across the stream. A set of latent AND-nodes — each tuned to a specific consecutive subpattern of the target — fire when the sensor sweeps past their pattern. They then sustain their activation for an independently adjustable number of strides, staying "alive" while the window moves on.

At the top sits an inference node. But unlike the spatial demo's hard AND, this one fires when K out of N latent nodes are simultaneously active. K is a parameter.

That single change — from "all must fire" to "K must fire" — is the difference between recognition and prediction.

What K Controls

K = N (all nodes required):
The inference node waits for every subpattern to confirm. This is sustained full recognition — reliable, but conservative. With the default full-coverage wiring, the last detector confirms at the final target symbol. Other wiring settings may leave positions unchecked.

K < N (partial evidence threshold):
The inference node can fire once K detector traces are active, before the remaining fragments arrive. Partial evidence can also trigger on a non-target sequence. Its diagnostic value depends on coverage, sustain, and input statistics.

This is an early target-recognition event. The lab does not generate the unseen suffix or implement an error-correcting predictive-coding circuit.

The False Positive Experiment

Try this sequence:

  1. Fanin=2, K=1 → a short fragment supplies relatively weak evidence. Measure the false-positive count over enough negative trials instead of assuming errors will appear in every short run.
  2. Fanin=5, N=3, K=2, sustain=7 → with the default target, the first target event occurs at zero-based stride 7.
  3. Fanin=5, N=3, K=3, sustain=7 → all three detector traces are required. The default target first fires at stride 10, its final symbol. Here K=3 is exactly K=N.

This controlled experiment illustrates the tradeoff between earlier commitment and complete evidence. Non-target sequences are sampled uniformly here; natural input statistics and real-task prediction accuracy are not measured. Repeated or overlapping detector fragments are not independent evidence.

Sustain as Working Memory

When a latent node fires and sustains, it's holding a trace — "I saw ABRAC a few strides ago." That trace needs to stay alive long enough to overlap with later subpattern matches.

Too short sustain → early matches fade before late ones confirm → false negatives.
Longer sustain → more separated matches within one sequence can coexist, potentially admitting additional non-target sequences. Traces are reset between sequences.

The sweet spot is determined by the temporal spread of the subpatterns across the sequence. This is a computational analogy to temporary retention, not a biological working-memory model.

The model uses position-aligned target fragments and resets traces between sequences. It does not model recurrent biological circuits, clinical conditions, or subjective experience.
