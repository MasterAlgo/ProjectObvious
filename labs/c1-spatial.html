...if you wire them properly

Imagine an 11-node input layer where each node can hold one of 5 discrete signal grades. The target sequence "ABRACADABRA" has exactly 11 symbols and 5 unique letters. The full input space has 511 = 48,828,125 possible states.

Above the input layer sits a small latent layer of hard AND-nodes. Each latent node is configured from a specific subset of target positions and fires only if all of those positions match — like the substring "ABRAC" at positions 0–4, or "CADA" at positions 4–7. This is a hard-AND toy detector, not a biophysical neuron model.

At the top sits a single inference node — a hard AND over all latent nodes. It fires only when every latent node fires simultaneously.

The Key Question

How many false positives does this network produce when fed random patterns?
A false positive means: a random input (not "ABRACADABRA") causes the inference node to fire anyway — a spurious recognition.

What the Demo Measures

These configured hard-AND nodes check exact target symbols. If their union covers U distinct positions of an input drawn uniformly from an alphabet of G symbols, the unconditional match probability is G−U. A position checked twice is still only one constraint. Compare actual coverage, not simply the number of nodes or wires.

Overlap mode samples consecutive windows. Disjoint mode partitions positions and caps each node at the requested fan-in; its effective fan-in may be smaller. Wiring modes therefore need not have equal coverage or equal wire counts.

Limits of This Experiment

Random negatives and periodic target presentations are sampled, not exhaustive. Zero observed false positives gives no guarantee of zero population error. The target is wired into the detector, not learned, and full target identification requires checking every position. These results do not establish why biological receptive fields overlap.
